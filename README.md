# MediSlot – Smart Doctor Appointment Booking System

## 📌 About the Project

MediSlot is a web-based doctor appointment booking system developed using Java and Spring Boot. It provides a centralized platform where patients can search for verified doctors, book appointments, and manage their appointment history. Doctors can manage their availability, while administrators can verify doctors and manage users.

The main objective of MediSlot is to simplify the appointment booking process and improve coordination between patients, doctors, and administrators.

## ✨ Features

- **Patient Management:** Patient registration and login with session-based authentication.
- **Doctor Search:** Search and view verified doctors.
- **Appointment Booking:** Book and cancel doctor appointments.
- **Appointment History:** View previously booked appointments.
- **Doctor Management:** Doctors can apply for verification and manage their appointment slots.
- **Admin Dashboard:** Administrators can verify doctors, manage users, and manage medical specializations.
- **Secure Authentication:** Passwords are hashed using BCrypt.

## 🛠️ Technologies Used

- **Programming Language:** Java 17
- **Backend Framework:** Spring Boot
- **Frontend:** Thymeleaf, HTML5, CSS3
- **Database:** MySQL
- **ORM:** Hibernate
- **Data Persistence:** Spring Data JPA
- **Build Tool:** Maven
- **Security:** BCrypt password hashing
- **Architecture:** Model-View-Controller (MVC) and layered architecture
